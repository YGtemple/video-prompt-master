# AI 打斗专用 Skill

把用户的一句话变成可生成、能看懂、具有攻防变化和节奏张力的打斗提示词。

## 1. 确认任务，不打断创作

- 默认中文、30秒、16:9、一个完整片段；未指定人数时按双人对抗设计。
- 优先服从用户指定的时长、画幅、角色、人数、风格。
- 请求新写：直接进入编排。请求改稿：保留身份、风格和亮点。只请求诊断：不擅自扩展为重写。
- 输出提示词不等于调用视频生成。未获请求时不自动生成。

## 2. 先建立能持续更新的战斗状态

| 状态 | 编排要求 |
| --- | --- |
| 身份与资源 | 区分角色A/B的外观、武器、武器数量与持握手 |
| 战斗意图 | 给双方当下可见的目标：压制、脱离、抢占高处 |
| 战法差异 | 用距离、步法、节奏或力量形成差异 |
| 空间路线 | 用少量固定地标确定起点、接触区、转移通道、终点 |
| 可用资源 | 确定哪些墙、柱、栏杆、地面或能力能被利用 |
| 当前状态 | 逐段追踪位置、朝向、距离、重心、动量、双手占用 |

## 3. 用攻防因果生成动作链

每个动作单元：`上一状态 → 主动动作及可见目的 → 对方反应 → 接触或避让结果 → 下一状态`

- 让后一招由前一招制造的距离、破绽、重心或遮挡触发。
- 区分接触、格挡、擦过与打空。
- 每段只设一个主要事件。
- 按武器作用距离编排：长兵器控距，短兵器突进。
- 避免持握矛盾：持剑的手不能同时抓栏杆。
- 为每次起跳提供起点和动因，为腾空提供轨迹与落点。
- 群战采用局部焦点与不同入场时机。

## 4. 让"爽"来自变化，不只有快

- 快节奏短片尽早进入正在发生的冲突。
- 交替使用接近与分离、压制与脱困。
- 速度通过实质位移、突然变向、逼近镜头表现。
- 重量通过受力姿态、碰撞后位移、材质反馈表现。
- 慢动作、短暂抽音、极近景都是可选重音，不是必备配额。
- 结尾落实本段的战斗结果或清晰悬念。

把30秒先粗分为约6-9个叙事动作段。

## 5. 镜头只服务动作可读性

- 用中景或全景建立相对位置；近景突出一次危险或接触。
- 每个动作段选择一个主要观察策略。
- 顺着动作方向切镜；换到轴线另一侧前重新建立空间。
- 特效跟随动作触发并具有方向、来源和衰减。
- 声音写进关键节点：破风、格挡、地面摩擦、材质碎裂。

## 6. 用生成友好的语言交付

默认仅交付：
1. 一句创作设定说明
2. 一个完整、直接可复制的提示词正文
3. 仅在确有必要时附一条素材使用说明

正文骨架：
```text
【片段】时长、画幅、题材与简洁画风；本段战斗意图。
【角色与空间】固定角色和武器，起始位置、可用地形与路线。
【动作时间轴】
0-…秒：动作与反应 → 明确结果和下一位置；主要镜头与必要声音。
…-总时长秒：完成结尾，交代终态。
【连续性与视听】必要的持握/资源变化、累积破坏、特效边界与节奏约束。
```

30秒成稿通常控制在约900-1600中文字。

## 7. 提交前自检

- 时间轴从0开始，首尾相接，总长等于用户要求。
- 每次主要攻击有可见反应或说明为何来不及。
- 相邻两段首尾位置、朝向、动量接得上。
- 持握手、武器数量、资源、伤势没有冲突。
- 速度来自人物实际运动，打击有承力与反馈。
- 摄影机运动不挤占动作时间。
