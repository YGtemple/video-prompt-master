# MJV8 中式诗意巨物美学

先把用户的简短想法扩写为独立可复制的英文图片提示词；用户生成图片并上传后，再依据实际成图输出约 4 秒的中文图生视频动态提示词。

## 两阶段工作流

| 输入 | 执行阶段 |
| --- | --- |
| 一句话、新题材 | 图片阶段：生成英文提示词 |
| 上传成图、"让这张图动起来" | 视频阶段：每张图给一个约4秒中文动态提示词 |

## 图片阶段：先确定用户要什么

- 数量：单个画面出1条，"一组"出6条。
- 画幅：默认16:9；竖屏壁纸9:16；人像3:4。
- 人物：纯景可用舟/桥/民居作尺度参照。
- 用户只给风格名未给题材时，采用"巨荷水乡里的夏日闲游"。

## 固定风格骨架

**核心定位：以真实摄影观感呈现可居、可游的中式超现实自然世界。**

| 维度 | 特征 |
| --- | --- |
| 世界设定 | 自然物放大到空间尺度：荷叶=亭盖，花朵=山体，植物冠层覆盖街巷 |
| 尺度证据 | 人、舟、瓦房、桥等熟悉物明确对比 |
| 人物关系 | 人在世界里生活：乘凉、倒茶、垂钓、撑舟 |
| 主色 | 青绿/灰绿/墨绿底色，天青/水蓝拓开空间，米白/藕粉/浅杏点亮 |
| 光线 | 自然光；侧逆光透过薄花瓣；叶下保留深色阴影 |
| 材质 | 叶脉有厚薄，花瓣有柔韧褶皱，衣料有织纹，水面有涟漪 |
| 空间 | 前景遮挡、中景活动、后景环境建立层次 |
| 气质 | 轻盈、温润、悠然，奇观与生活并存 |

## 构图与场景编排

| 构图 | 适合画面 |
| --- | --- |
| 水面低机位 | 小舟穿行、仰看荷叶冠层 |
| 斜俯视 | 叶上垂钓、清水池塘 |
| 中景生活群像 | 叶下喝茶、乘凉 |
| 环境人像 | 舟上或花前的半身/全身肖像 |
| 框景远景 | 桥洞内的巨莲 |
| 高处眺望 | 屋顶人物、古镇与植物天幕 |

## 编写英文提示词

推荐顺序：景别/机位 → 主体与动作 → 环境及尺度证据 → 构图关系 → 光色 → 2-4个材质证据 → 整体摄影观感 → 参数。

- 控制在约 70-120 个英文词。
- 每条独立包含风格与人物必要信息。
- 不用 `tiny woman`，用 `a normal-sized adult woman dwarfed by...`。

## 图片模型与参数

起始后缀：
```text
--ar 16:9 --v 8.2 --raw --s 100 --no text, watermark, logo, anime, cartoon
```

不添加 `--q`、`--cref`、`--oref`。`--s 100` 是起点，50-100用于更强内容约束，150-250探索装饰观感。

## 成图后的约 4 秒动态规则

默认每张图输出一个约4秒的连续镜头，包含一种主要运镜或固定机位 + 一个主要动作 + 少量有因果的环境运动。

守住面部、发型、服装、人数、植物结构、建筑透视、主色与原有光向；让水纹、衣料和阴影随运动自然变化。

视频提示词默认用中文自然语言，标题为"图片01｜约4秒动态提示词"，内容顺序：首帧与画幅承接 → 镜头路径 → 主体动作 → 环境联动 → 稳定约束。约150-300个汉字。

## 发出前自检

- 奇观有没有实际尺度证据？
- 主色、自然光、材质是否协调？
- 是否误加现代物品、霓虹、游戏CG？
- 视频动作是否从首帧已存在的姿态开始？
